Privacy Policy

Hermes Mail Digest · last updated 6 October 2026

Hermes Mail Digest ("the app") is a private, single-user automation operated by its owner on the owner's own server. This policy describes how the app accesses, uses, stores, and shares Google user data. The only Google Account it ever accesses is the owner's own account, with the owner's explicit consent.

1. What data the app accesses

Gmail (read)gmail.readonlyReading the owner's inbox to identify messages that need a reply, an action, or a deadline.

2. How the data is used

  • To build a short daily briefing for the owner from the owner's own mail, and to answer the owner's requests about the owner's own data.
  • Data is used only for these purposes. It is not used for advertising, profiling, credit assessment, or any purpose unrelated to delivering this personal tool to its owner.
  • The app does not use Google user data to train, fine-tune, or otherwise develop machine learning or artificial intelligence models.
  • Automated processing is performed by large language models acting on the owner's behalf. The owner selects and pays for those model providers directly; message content is transmitted to the selected provider only to generate the owner's briefing and is not retained by the app for any other purpose beyond the local copy described below.

3. Storage and retention

  • An OAuth refresh token is stored in a local credentials file on the owner's own server, readable only by the owner's operating system account.
  • Briefing state (a small text list of outstanding items, each linked to a Gmail message identifier) and a per-day markdown file of generated briefings are stored locally on the owner's server.
  • Message bodies are read transiently while a briefing is generated. They are not copied into any external database, and no mail data is stored outside the owner's server.
  • Local state can be deleted at any time by the owner, which removes all stored briefing data.

4. Sharing

  • Google user data is not sold, rented, or shared with any third party.
  • It is not transferred to advertisers, data brokers, information resellers, or credit bureaus.
  • It is not used to determine creditworthiness or for lending purposes.
  • The only outbound destinations are the owner's own private chat channel (the generated briefing) and the model provider the owner has configured to generate it.

5. Limited Use disclosure

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Specifically: data is used only to provide the user-facing features described above; it is not transferred to others except as necessary to provide those features, to comply with applicable law, or as part of a merger or acquisition; it is not used for advertising; and no human reads it, except for the owner reading their own data, for security purposes, to comply with law, or with the owner's explicit consent.

6. Revoking access and deleting data

  • Access can be revoked at any time at myaccount.google.com/permissions. Revocation immediately ends the app's ability to reach the account.
  • Deleting the local credentials file and local state directory removes all stored tokens and briefing data.
